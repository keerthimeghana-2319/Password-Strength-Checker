\# Password Strength Checker



\## Project Overview

Password Strength Checker is a beginner-friendly cybersecurity project developed using Python. It evaluates password characteristics and provides feedback about password strength.



\## Objectives

\- Evaluate password length.

\- Identify uppercase and lowercase letters.

\- Detect numbers and special characters.

\- Identify a small set of commonly used passwords.

\- Display password strength and security suggestions.



\## Technologies Used

\- Python 3.11.9

\- Tkinter

\- Regular Expressions (re)

\- Visual Studio Code / Notepad

\- Windows CMD



\## Project Features

1\. Password strength evaluation.

2\. Security score out of 5.

3\. Common password detection.

4\. Graphical User Interface.

5\. Show and Hide password option.

6\. Visual strength indicator.

7\. Security suggestions.



\## Project Files

\- `password\_checker.py` – Command-line application.

\- `gui\_password\_checker.py` – Graphical application.

\- `screenshots/` – Application screenshots.



\## How to Run



\### Command-Line Version

```bash

python password\_checker.py

```



\### GUI Version

```bash

python gui\_password\_checker.py

```

This project is developed for educational purposes. Its scoring method is a basic demonstration and does not guarantee actual password security. Do not enter real or personal passwords into this demonstration application.
